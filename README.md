# Virtual Column Task

This repository contains my solution to the recruitment assignment.

The task was to implement a function that creates a calculated column in a pandas DataFrame based on a simple arithmetic expression while following the provided specification.

## Files

- `solution.py` – implementation of the required function
- `test_solution.py` – unit tests
- `requirements.txt` – project dependencies

## Requirements

- Python 3.12

## Installation

```bash
pip install -r requirements.txt
```

## Running tests

```bash
pytest
```

## Notes

The implementation follows the task specification and supports only the functionality required by the assignment.

The original DataFrame is not modified. Invalid input results in an empty DataFrame, as required by the specification.
